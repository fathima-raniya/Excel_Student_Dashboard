# Student Course Management System

A Microsoft Excel-based Student Course Management System developed using Excel formulas, VBA automation, and dashboards to efficiently manage student information and academic progress.

## Features

- Student information management
- Course tracking and progress monitoring
- Current topic and learning progress tracking
- Student review and performance records
- Staff–student assignment management
- Attendance tracking
- Student presentation tracking
- Course validity and batch management
- Interactive student dashboard
- Automated data retrieval using Excel formulas
- VBA-based functionality and automation

## Tools & Technologies

- Microsoft Excel
- Excel VBA
- Excel Formulas
- Dashboard & Data Visualization

## Purpose

This project helps simplify student management, monitor learning progress, maintain academic records, and organize course-related information in a centralized Excel workbook.
